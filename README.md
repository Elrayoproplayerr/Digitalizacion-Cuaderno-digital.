# LECTURA:
## Criptomonedas, ¿dinero sin bancos?
Las criptomonedas, como Bitcoin, funcionan gracias a una tecnología llamada blockchain, que registra todas las operaciones en muchos ordenadores, haciendo muy difícil modificar los pagos.

Para acceder a ellas se necesitan unas claves privadas. Si las pierdes o alguien te las roba, puedes perder todo tu dinero, ya que las operaciones no se pueden cancelar ni recuperar.

El texto cuenta cuatro casos reales de personas que perdieron sus bitcoins:

Stefan: olvidó la contraseña de un dispositivo donde guardaba 7.002 bitcoins y solo le quedaban dos intentos para desbloquearlo.

James Howells: tiró por error un disco duro que contenía las claves de 8.000 bitcoins.

Gabriel Abed: perdió las claves de 800 bitcoins cuando formatearon su ordenador sin hacer una copia de seguridad.

Un robo de 1,7 millones de dólares: un ladrón fotografió la frase de recuperación de un monedero y utilizó esa información para robar las criptomonedas.

Conclusión: Las criptomonedas permiten enviar y recibir dinero sin bancos, pero tienen riesgos importantes, porque perder o compartir las claves privadas puede suponer perder todo el dinero para siempre.
